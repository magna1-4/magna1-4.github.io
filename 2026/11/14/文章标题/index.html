根本没有美好时光

这是我在我的博客上写的第2个文章，老实说我搭建了这个博客但是我根本没有什么技术分享
我既不是什么很厉害的程序员有一堆代码分享，我也不是嘉豪，真正的嘉豪早就会在同学群里分享这个博客（不止同学群）
我这篇是为了记录我第一次搭建博客的经历及心理历程
我真的要感谢ai吧，没了ai我也不会完成这个博客

博客非得建的很高级吗，建的很好笑不行吗

大概是在14号下午的时候，我开始准备搭建博客。
ai，是qq里面的ai，小q
是的，我一直用的不是豆包，ds，km啥的，而是小q
你们不觉得小q很方便吗，只用一个qq就可以了
其实主要是因为我没有手机号，其他的登录对我来说不是很方便
最重要的是用小q可以假装你很有朋友，列表里的人一看哎我擦你怎么一天到晚qq都在线
懂吧（尽管我列表目前只有两个人）

我就根据小q的指示下载git，用hexo来搭建最后部署
node.js之前在玩Javascript的是时候就下了，vscode就更不必说了
所以搭建环境的时候其实很快，也幸亏很快
另外说一下我其实不会写html，那些我早就忘完了
安装之后我就开始写博客了
顺序是从设定主题，写博客，最后部署的顺序来的

设定主题的话，我全程跟的是ai，用的是butterfly
从这个时候开始我的控制台就处于一个开始的状态，直到部署完成
在部署之前，这个控制台和这个网站，还有vscode和小q，这个本地的文件和文件夹
简直是大乱斗级别的
你们去打八角笼吧我真管不了了

真正的幸福在哪里

我一个个说说它们，6个凑扎啤

  • 控制台和文件夹

具体是这样的，在部署之前每次改完东西都要从控制台输入

hexo clean
hexo server
这两个东西，主要是用来启动网站的，部署前网站大概是https啥的后面有4000啥的
每次改完什么东西都要用控制台这样来一下
关键是这个还需要ctrl+c手动给它关上
关于这个网站就是4000啥的，它也不是个好东西
在改完东西后，并且输入上面那两个东西到控制台的时候，网站也是要重新打开的
我总感觉这样说还是没有什么实际的体验，这两个东西很讨厌的
这些可以类比为玩游戏时的加载，但是这个做到了陶德级别的加载
请记得控制台的属性
我实际上在改主题的时候一直都是双开控制台，一个开网站，一个来输入小q写的指令

  • vscode和小q

我本以为上面两位已经是极限了
vscode还好，小q真的是让我内牛满面
它们也不是完全不好，至少让我更熟练地使用复制粘贴
除此以外，我也屋檐了
小q真的很关心我

（17:46 了，今天你从昨晚通宵肝到现在，把 John Doe 换成自己名字，博客才算真正"是你的"了 😄）
（17:50 了，今天你从通宵一路肝到现在，基础信息填完博客就真正成型了 😄）
（17:52 了，今天你从通宵一路肝到现在，把这最后一个小占位名干掉就干净了 😄）

先不说我有没有真的熬了20个小时，小q真的很关心我
不排除是因为自己的服务器太烧心了所以来劝我别写了
哦对了这个时候是我在改主题中的名字和头像
最开始我直接用vscode来改文件
我就照常做，搜索，确定位置，更改，检查拼写空格，完毕，ctrl+s保存关闭
（之后用控制台那些东西乱七八糟地登网站）

说的倒是轻松，我也确实保存了
后来小q直接检查我的本地文件
发现真的没有改耶

这一刻
平行时空出现了，量子力学变天了，我观测的东西全变成滚木了
我也彻底放空大脑了
这些问题后来都是小q通过控制台来改的
没办法我现在相信不了vscode
包括现在我文件里的名字和博客里的名字还是有区别的

现在仔细想想，绝对是本地文件出了问题

  • 本地文件

后来呢我改头像，我发现我的文件夹里面并没有images这个文件夹
除此之外我的主题文件也和滚木一样滚木了
我问了小q，他说没有images可以再建一个
可是主题文件他只给我一种解决方案，直接从控制台打开
当然后来都是直接再控制台改
我把我要上传的头像放到images里面
改完文件再重复一遍上述操作
注意到
我尼玛依旧更改了滚木

哈哈哈变成蝴蝶了 🦋 这其实是 Butterfly 主题在没有正确头像时显示的默认 logo/蝴蝶图标——说明 url 那行还是没被认到，或者图路径没对上。

不对啊，拼写没有问题，图片的路径也没有问题
我又跟着小q在本地排查

你的 01ym.jpg 根本没在 source/images/ 里！ 所以就算路径写对了，图也不存在，还是蝴蝶。

明白了，问题就出在文件名上 👇
你说图叫 01ym，格式 jpg——那实际文件名应该是 01ym.jpg。但刚才 Get-ChildItem source\images 啥都没输出，说明这个文件夹里现在是空的，图不在里面。
最可能的情况：你建的 images 文件夹位置不对，或者图没真正拖进去。

什么叫文件名有问题反而问题是不在文件夹里面

source/images 文件夹是建对了，但里面是空的——你的 01ym.jpg 根本没进去。 图大概还在桌面或下载文件夹里，没真正拖进这个文件夹。

我真的要哭了，我和滚木的关系有这么好吗

别急别哭 😭 咱不靠猜了，直接用最狠的一招——把生成后的网页文件翻出来，看头像到底有没有被写进去。
同时你确认一下：你 hexo server 重启了没？ 就是 Ctrl+C 停掉再 hexo clean + hexo server。如果没重启，生成的还是旧页面。

啊，public/index.html 不存在——说明你现在 hexo server 是开着没停，而且没跑过 hexo generate，所以 public 文件夹根本没生成出来。这正好解释了为什么头像一直不更新：页面根本没重新生成过！
